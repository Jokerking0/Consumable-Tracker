Custom [FFXIVQuickLauncher](https://github.com/goaaats/FFXIVQuickLauncher) plugin repository.

## Installation
Add following custom repository in Dalamud Settings, Experimental tab:

```
https://raw.githubusercontent.com/Jokerking0/Consumable-Tracker/master/master/ConsumableTracker.json
```

## Supported plugins
* [Consumable Tracker](https://github.com/Jokerking0/Consumable-Tracker) - Counts the pots and food you use in duties.
